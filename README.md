# 打字小伴侣

Windows 桌面小伴侣与设置界面分开运行。键盘事件由 Raw Input 接收，不读取或保存键入文字。

## 运行

直接双击项目根目录的 `TypingPet.exe` 启动，无需 PowerShell 或 .NET SDK。此单文件 EXE 使用本机安装的 .NET 8 Windows Desktop Runtime。完全退出旧实例后，再双击 EXE 启动新版；开发时仍可使用 `运行.ps1` 或 `dotnet run`。

## 设置组与图片组

- 窗口顶部的 A–E 按钮是五个阈值设置组。**显示计数**（实际输入次数 × 系数）达到阈值时，桌宠切换到该设置组关联的图片组；编辑中的设置页不会跟着输入跳组。窗口标题下方会显示桌宠当前实际使用的设置组和图片组。
- 设置组只保存输入次数阈值和图片组关联。动效、系数、状态停留时间等均为全局设置。
- 可关闭“按阈值自动切换设置组”；关闭后桌宠保持当前手动选择的设置组。改动先暂存，点击“应用全部设置”后才影响桌宠。
- 参数页可以为当前设置组选择图片组。图片管理页可创建/删除图片组，使用“应用到设置组”快速关联当前图片组。
- 参数预览下方可切换简易/高级状态模式，并提供慢、中等、快及重置预设。输入状态有最短显示时间，状态计时不会在新输入刚发生时抢先切到待机或暂停。
- 图片组包含待机、暂停、输入中、回车系、回退系、大小写切换六类状态，界面按此顺序排列。图片管理页以从左到右排列的卡片显示较大缩略图和文件名，并支持拖放、排序、添加、删除和清空。
- 图片管理页可选中单张卡片后使用剪切、复制、粘贴按钮或 Ctrl+X/C/V。复制会在目标状态末尾追加图片；剪切会在粘贴成功时移动图片，也可跨图片组使用。从文件管理器复制图片文件或复制位图后，也能粘贴到当前状态。修改后点击“应用全部设置”使桌宠采用新图片。
- 选中图片后点击“裁切 3:4”可打开固定竖版宽:高 3:4 的取景框；拖动选择位置，用滚轮或按钮调整范围。保存后图片组改用新裁切图，原文件保留，点击“应用全部设置”后桌宠生效。
- 图片组页可拖放图片，也可用添加按钮多选。支持 PNG、JPG/JPEG、BMP、GIF（读取首帧）、TIF/TIFF、ICO；损坏和不支持的文件会跳过。
- 全局简单/高级模式控制暂停与大小写切换扩展动效，并设置每状态图片数量上限：简单模式最多三张，高级模式最多二十张。

## 计数与动效

- 小伴侣下方独立显示累计数字。全局系数可设为 0.2–10；实际输入次数跨退出和重启保留，只有点击“重置计数”才会主动清零并按阈值回到首个设置组。计数和设置保存在 `%LOCALAPPDATA%\TypingPetPrototype`。
- 计数累计可打印键和回退键的按下事件，不读取文字；中文输入法组合出的汉字数不会等同于物理按键数。
- 可选跳动式或形变式并调整幅度。高级模式可调整输入保持、暂停、回退和回车停留时间。
- 桌宠仅显示当前状态的导入图片，不显示底板。跳动改变图片位置；形变在图片或大小变化时预先生成并缓存少量形变帧，输入时只切换帧，不逐帧缩放图片或窗口。生成帧时按 Python 参考项目的做法清理缩放后的半透明边缘。鼠标滚轮可在 40%–600% 间缩放，放大时尽量保持图片在当前屏幕内；左键可拖动；右键可重置大小或显示/隐藏数字。
- 桌宠缩放比例、桌面位置和数字显示状态会在退出后恢复。旧设置没有缩放记录时，首次使用新版默认 200%；后续沿用最后一次调整的大小。
- 滚轮改变缩放时，透明可见区域与预生成的形变图片帧同步扩大或缩小，避免只显示放大图片的一小块。
- 关闭设置窗口会将其收进系统托盘，桌宠继续运行。可从托盘打开设置或完全退出；也可右键桌宠完全退出。
